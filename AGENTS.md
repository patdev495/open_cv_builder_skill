# AGENTS

Instructions and capabilities for AI agents in this repository.

## Agent skills

Issues and PRDs for this repo live as GitHub issues. See `docs/agents/issue-tracker.md`.

Triage labels map to standard status labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository with a global CONTEXT.md and docs/adr/. See `docs/agents/domain.md`.
